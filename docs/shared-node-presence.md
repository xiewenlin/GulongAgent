# 共享节点在线状态（管理员）

管理员后台 → 共享模型状态 → 查看共享节点：每个节点名称后展示 18px 状态圆点及中文标签。绿点「在线」、红点「离线」、灰点「状态未知」。悬停可查看最近心跳时间。

`GET /api/admin/capability-consumers/bindings` 延用现有管理员登录鉴权、精确节点 ID / 名称关键词搜索及最多 50 条限制，响应不缓存，不包含邮箱或绑定令牌。新增响应字段：

```json
{
  "checked_at": "2026-10-23T04:00:00.000Z",
  "heartbeat_window_seconds": 180,
  "presence_unavailable": false,
  "bindings": [{
    "binding_id": "...", "node_id": "...", "node_name": "培训 1 号机",
    "user_id": "...", "compute_group_id": null,
    "online": true, "online_status": "online",
    "last_seen_at": "2026-10-23T03:59:59.000Z",
    "online_expires_at": "2026-10-23T04:02:59.000Z"
  }]
}
```

取有效绑定 `lastSeenAt`、同一 bindingId + nodeId 的统一消费者 `reportedAt`、自动库存 `reportedAt` 中最新的服务端时间。仅距离服务器快照时间小于 180 秒才在线；无心跳或已过期为离线。绑定更新时间、注册时间、激活时间、验收通过或待验收都不是心跳。读取异常返回 unknown，不妨碍查看绑定及算力分组。批量读取两类上报，不按每个节点分别查询。

页面可见时每 15 秒安静刷新当前已提交的搜索条件，并按单调时钟使陈旧绿点自动过期；后台标签页暂停刷新，返回时立即更新。自动刷新不重置选中节点、算力分组编辑或待确认操作。401/403 仍清除受保护内容。

在线状态仅读取已存在的服务器记录，不查询局域网、不创建验收挑战、不执行模型、不创建订单，也不表示 GPU 空闲、模型验收通过或允许派单。软件发布不会自动激活模型验收窗口或推理预算。
